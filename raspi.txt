## Raspberry Pi 5 Setup

### 1. Update the system

```bash
sudo apt update
sudo apt upgrade -y
sudo apt install -y git python3 python3-pip python3-venv
```

### 2. Install system dependencies

```bash
sudo apt install -y python3-picamera2 python3-opencv
sudo apt install -y libzbar0
```

### 3. Clone the repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd Squadrone
```

If the repository is already cloned, update it instead:

```bash
cd ~/Squadrone
git pull
```

### 4. Create and activate a virtual environment

```bash
python3 -m venv --system-site-packages .venv
source .venv/bin/activate
python -m pip install --upgrade pip
```

### 5. Install Python dependencies

```bash
python -m pip install pyzbar
```

Install any additional Python packages required by the project.

### 6. Verify camera and QR dependencies

```bash
rpicam-hello --list-cameras

python3 -c "from picamera2 import Picamera2; print('Picamera2 OK')"

python3 -c "import cv2; print(cv2.__version__); print(hasattr(cv2, 'wechat_qrcode_WeChatQRCode'))"

python3 -c "from pyzbar.pyzbar import decode; print('pyzbar OK')"
```

The OpenCV check should return `True` for WeChatQRCode support.

### 7. Run QR detection

```bash
python QR_ID/qr_onboard.py
```

Ensure the WeChatQRCode model files are present in `QR_ID/models/`.
